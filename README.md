3D tutorial Game built to serve as a refresher in Godot.

Decided to code the game in Godots native language, GDscript as I wanted to develope my skills in this language further

This project was built using the Godot tutorial docmentation which you can find here: 
https://docs.godotengine.org/en/stable/getting_started/first_3d_game/index.html

I do not claim this as my own work, merely a small project to re-familiarize myself with Godots 3D engine and get a basic refresher into GDscript.
